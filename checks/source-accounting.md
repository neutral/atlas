# Account for supplied source material

Record how each material source unit is handled.

## Requirement

For the declared source scope, account for every material claim, decision,
constraint, question and evidence unit. Record an update, creation, Facet,
conflict, reference-only addition or justified non-integration. Preserve source
locations, uncertainty and conflicting meanings.

## Verification

Read the complete declared source within granted access. Record each material
unit's source location, candidate identities, disposition and reason. Compare the
result with the affected Points, higher explanations and Facets. Report any
uninspected source or unresolved disposition.

## Failure

Fail when a material unit disappears, duplicates an existing contribution, loses
its source boundary or receives no defensible disposition. Report unable when
required source access is unavailable.

## Exceptions

For an original edit or mechanical change, record the limited scope in the
evaluation instead of a source inventory.
