# Keep routing questions usable

## Requirement

Each Map question must define a durable perspective that is distinct across the Atlas. Each Area question must define a useful overlapping scope that is distinct within its Map. A routing question must help an author decide where information belongs. A title, category label, repository folder, or generic request for related information is not sufficient.

## Verification

Compare each changed question with all Map questions and with the Area questions in its containing Map. Record the nearest alternatives and the distinction between them. Test the question against representative information from the proposed scope and confirm that it guides a deposit decision without requiring an unstated project convention. Inspect the Map prose and summaries for the same boundary.

## Failure

Fail when a question duplicates or paraphrases another scope, mirrors physical organization without a semantic reason, accepts nearly any information, or cannot guide a stable deposit choice. Rederive, merge, split, or remove the affected scope.
