# Atlas documentation

Atlas makes the context around a project navigable, helping agents and people
build a better understanding.
Use it to explain project knowledge, find the detail behind an account and keep
that understanding current as the project changes.

Start with the [guided example](../examples/README.md): ask what happens to a
note while offline, follow the explanation into another Tree, and inspect the
source behind the claim. Then [open your own project](getting-started.md).

The reading path is deliberate: discover a relevant Point, read its full
explanation, then follow its detail, Facets and sources. When new material changes
that understanding, retain the reasoning in a draft and review the candidate
before applying it.
