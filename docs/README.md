# Atlas documentation

Atlas makes the context around a project navigable, helping agents and people
build a better understanding.
Use it to explain project knowledge, find the detail behind an account and keep
that understanding current as the project changes.

Start with [your first Atlas](getting-started.md), or choose the task below.

## Use Atlas

| Task | Guide |
| --- | --- |
| Set up Atlas on your machine | [Install Atlas](install.md) |
| Open a project or create its first account | [Get started](getting-started.md) |
| Choose Trees, develop Points and connect perspectives | [Organize knowledge](organizing-knowledge.md) |
| Find an explanation and follow its detail and sources | [Read an Atlas](reading.md) |
| Change content, review a draft and recover interrupted work | [Edit an Atlas](editing.md) |
| Connect an agent, ask questions and integrate new material | [Work with an agent](working-with-agents.md) |
| Review project requirements and their evidence | [Use Checks](reviewing-checks.md) |
| Select content and export a static site | [Publish an Atlas](publishing.md) |
