# Atlas CLI

Run `pnpm atlas open PROJECT` from the repository to open a project in the Editor.
Use `pnpm atlas --help` for command syntax. A complete distribution provides the
`atlas` and `atlas-cli` executables.

For an agent or a script, start with a compact discovery request, then Route an
exact Point or Tree-local Facet returned by it. Read `inspect style` before
placing or developing knowledge, and use `styles` to inspect curated choices:


```sh
printf '%s\n' '{"query":"offline delivery","mode":"discover","limit":5}' |
  pnpm atlas --root examples/offline-notes route -
```

Route returns selectors for exact reading and `next` requests when more results
remain. Use `references` to find direct citers and `sources` to review declared
source bytes within explicit grants. `source-history` reads retained observations;
`source-record` explicitly saves an observation or a decision about exact bytes.
Compact inventory and draft summaries omit bodies; use exact inspection, `--full`
or `part: "details"` chunks to read the complete material. `absorb prepare` saves contribution reasons
with the proposed change; `draft-review` exposes its reasoning and affected
accounts, and `draft-checks` records evidence against that candidate. Applying
requires the reviewed draft's exact revision.

The [command reference](../../docs/reference/cli.md) defines the JSON inputs,
source grants, result bounds and exit codes. See [reading paths](../../docs/reference/reading-paths.md)
for discovery and continuation, and [Absorb review](../../docs/reference/absorb-review.md)
for retained proposal reasoning.
