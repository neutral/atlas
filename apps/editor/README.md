# Editor

The Editor turns an update into a draft you can read before it changes the Atlas.
Open a Point, revise its explanation and select **Save and review**. Review shows
what changed, which surrounding accounts and direct citations deserve attention,
and the complete before and after files. Apply the exact saved revision when it
is ready.

An Absorb draft keeps the reasoning behind each contribution and its unresolved
questions when reopened. Review adopted Checks against the candidate and retain
their evidence with the draft. When an edit relies on exact source bytes, inspect
the cited source and explicitly require those bytes at application. **Move file**
prepares a move and supported inline link repairs together for review.

Start with [editing an Atlas](../../docs/editing.md) for these review paths and
recovery, or [getting started](../../docs/getting-started.md) to create an Atlas.

`startEditor(root, options)` starts the shared Portal service with editing enabled.
The launcher fixes source access and private storage. The
[authoring reference](../../docs/reference/authoring.md) defines draft revisions,
application preconditions and interrupted-write recovery.

The interface also supports [agent connection](../../docs/working-with-agents.md),
[Check inspection](../../docs/reviewing-checks.md) and
[publication](../../docs/publishing.md). Its implementation lives in the shared
[Portal](../portal/README.md) service and browser assets.
