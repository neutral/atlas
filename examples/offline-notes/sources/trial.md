# Fictional trial — 2026-09-20

This invented result demonstrates how to record the scope of an observation. It
is not evidence about a real application.

## Conditions and result

In one demonstration run, the app had no network connection. A writer created a
note, waited for the local-save indication, closed the app normally, and reopened
it on the same device while still offline. The note's text was available.

## Limits

The run did not interrupt a write, terminate the app unexpectedly, remove device
storage, or cut power. It did not reconnect, contact a server, open another
device, or create a conflicting revision. No claim about those outcomes follows
from this result. Repetition across devices and storage conditions is untested.
