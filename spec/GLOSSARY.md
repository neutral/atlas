# Atlas Glossary

> Status: Released

- **Anchor record:** The one Point record that establishes an Atlas-wide Point identity and its primary Map.
- **Area:** A non-exclusive Map-local concern with a placement question.
- **Area membership:** An explained edge stating how a Point record affects an Area question in its Map.
- **Atlas:** One portable project-context boundary and namespace.
- **Check:** Project-local write policy that adds requirements without redefining core meaning.
- **Content:** Primary material that directly represents an Atlas, Map, Area, or Point record.
- **Context record:** A non-primary Map's contribution explaining the significance of the same Point without redefining its canonical idea or state.
- **Derived Map relationship:** Symmetric overlap computed from shared Point identities, not inferred task relevance.
- **Lifecycle:** Whether a Point is active, historical, superseded, or withdrawn; not a workflow for edits.
- **Map:** A durable semantic and deposit domain with a primary question and Area vocabulary.
- **Open-world relation graph:** Known authored relations whose omissions establish no absence of relationship or impact.
- **Point:** One independently referable item of context with coherent posture and lifecycle, represented by one anchor and optional context records. See the identity rules in [SPEC](SPEC.md#point).
- **Point record:** One physical Markdown file for a Point in one Map's direct `points/` directory.
- **Posture:** Whether a Point is asserted, open, proposed, or intended; not evidence strength or implementation maturity.
- **Primary Map:** The Map containing the anchor. It records provenance, not exclusive ownership or preferred routing.
- **Publication profile:** An explicit allowlist of Atlas source records and registered Resources.
- **Reference:** Typed evidentiary, supporting, implementation, historical, or example material.
- **Relation:** A directional, explained link between Point identities.
- **Resource:** Addressable material, optionally registered with stable Atlas-wide identity.
- **Substantive body:** Markdown with at least one included block under the body-inspection rules in [Processing](spec/PROCESSING.md#body-inspection).
