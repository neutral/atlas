# Atlas Glossary

> Status: Working

- **Anchor record:** The one Point record that establishes an Atlas-wide Point identity and its primary Map.
- **Area:** A non-exclusive Map-local region or concern with a placement question. Areas may overlap.
- **Area membership:** An explained semantic edge from one Point record to one Area in the record’s Map. It contains the Area id and context that states how or why the record affects the Area question.
- **Atlas:** One portable project-context boundary and namespace.
- **Check:** Project-defined authoring policy outside mapped context.
- **Content:** Primary material that directly represents an Atlas, Map, Area, or Point record.
- **Context record:** A Point record in a non-primary Map that adds Map-local summary, explained Area memberships, Content, References, or body context to an existing Point.
- **Derived Map relationship:** Symmetric overlap that processors compute when one Point has records in more than one Map.
- **Lifecycle:** Whether a Point is active, historical, superseded, or withdrawn.
- **Map:** A durable semantic and deposit domain with a primary question and Area vocabulary.
- **Point:** One Atlas-wide context identity that combines exactly one anchor record with zero or more context records.
- **Point record:** One physical Markdown file for a Point in one Map’s direct `points/` directory.
- **Posture:** Whether a Point is asserted, open, proposed, or intended. Posture does not establish evidence strength or implementation maturity.
- **Primary Map:** The Map containing a Point’s anchor record. It anchors provenance and default interpretation but does not own all Point context.
- **Publication profile:** An explicit allowlist of Atlas source records and registered Resources that may be published.
- **Reference:** Typed evidentiary, supporting, implementation, historical, or example material.
- **Relation:** A directional, explained semantic link from one Point identity to another.
- **Resource:** An addressable document or artifact, optionally registered with stable Atlas-wide identity.
- **Substantive body:** Markdown that states context rather than containing only headings, metadata, or navigation links.
