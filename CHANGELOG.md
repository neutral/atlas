## 0.7.0 - 2026-08-29

This is the first public release of the current Atlas specification.

- Establishes Atlas as a portable format for making context between project documents explicit and navigable.
- Defines format 1 around question-led Maps, overlapping Areas, Atlas-wide Points, Resources, Checks, and publication profiles.
- Defines deterministic processing, validation, normalized output, and conformance boundaries.
- Provides the public specification, schemas, executable fixtures, contribution guidance, and CC0 dedication.
