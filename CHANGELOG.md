# Changelog

## 1.0.0

Atlas makes the context around a project navigable, helping agents and people build a better understanding.

- Organize knowledge into Trees, from broad explanations to detailed Points,
  with Facets connecting perspectives and references linking to source material.
- Develop context with Absorb and navigate it with Route, keeping reasoning,
  evidence and uncertainty visible.
- Read and author through the browser, command line and agent tools, with
  reviewed changes, durable drafts and recovery.
- Run Atlas locally using packages or portable bundles, and share selected
  knowledge through static publications.
